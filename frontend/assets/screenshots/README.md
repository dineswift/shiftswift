# Marketing screenshots

Drop redacted admin captures here (WebP or PNG preferred). Replace the SVG placeholders on the landing page when ready.

## Capture checklist

1. Log into a pilot tenant on `app.shiftswifthr.co.uk`
2. Capture at **1440×900** (or 2× for retina)
3. Redact: names, emails, NI numbers, addresses, employer names if sensitive
4. Export as:
   - `admin-overview.webp` — dashboard / home
   - `time-clock.webp` — Time Clock + hours export
   - `compliance.webp` — RTW or sponsor compliance workspace

## Update `frontend/index.html`

Replace `src` on `.product-showcase-card img` elements and update `alt` text to mention redacted sample data.
