# Play Store screenshots — ShiftSwift HR

Generated from emulator captures (employee portal).

## Upload guide

### Phone (required)
Folder: `phone/` — **1080 × 2160** PNG (within Play’s 2:1 limit, full UI visible)

Upload order (recommended):
1. `01-sign-in-chooser.png` — Who is signing in
2. `02-employee-home.png` — Employee home
3. `03-my-shifts.png` — My shifts
4. `04-leave-holiday.png` — Leave & holiday

Play Console → Store listing → Phone screenshots

### 7-inch tablet
Folder: `tablet-7/` — **1200 × 1920** PNG  
Same four filenames.

### 10-inch tablet
Folder: `tablet-10/` — **1600 × 2560** PNG (portrait)  
Optional landscape: `tablet-10-landscape/` — **2560 × 1600** PNG

## Notes
- Sources were Mac window captures; assets are upscaled + padded to store sizes.
- For sharper tablet shots later, capture on `Medium_Tablet` AVD with `adb exec-out screencap -p`.
